# HouseBuilder

Веб-приложение для проектирования жилья под реалии Украины: планировка квартиры или дома с участком,
отделка, мебель и конструктор корпусной мебели (деталировка, раскрой), инженерные системы, ландшафт,
3D-прогулка, чертежи (PDF/DXF) и смета.

```bash
npm install
```

```bash
npm run dev
```

Локально приложение открывается по адресу http://localhost:5173/housebuilder/. Публикация — GitHub Pages
(`.github/workflows/deploy.yml`, push в `main`): https://d1mocha.github.io/housebuilder/

Подробности — в [REPORT.md](REPORT.md): что сделано, что упрощено, известные проблемы, дальнейшие шаги.
Архитектура — [ARCHITECTURE.md](ARCHITECTURE.md), решения — [DECISIONS.md](DECISIONS.md).

> Приложение не заменяет проект сертифицированного специалиста. Нормативные значения в справочнике
> не проверены и требуют сверки с действующими ДБН/ДСТУ/ПУЕ.
